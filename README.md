# 🏫 نظام إدارة المعاهد (Institute Management System)

تطبيق سطح مكتب متكامل تم تطويره باستخدام (C# Windows Forms) لإدارة العمليات الإدارية والأكاديمية للمعاهد بكفاءة، يشمل إدارة شؤون الطلاب والمتدربين، الدورات التدريبية والمواد، عمليات التسجيل، واستخراج التقارير المتقدمة.

---

## 🛠️ التقنيات المستخدمة
* **لغة البرمجة:** C# (C-Sharp)
* **الواجهة الأمامية:** Windows Forms (.NET Framework)
* **نظام التقارير:** SAP Crystal Reports
* **قاعدة البيانات:** SQL Server / ADO.NET
